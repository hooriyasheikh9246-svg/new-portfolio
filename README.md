# Portfolio — Hooria Usman

A responsive front-end portfolio built with semantic HTML5, modern CSS and vanilla JavaScript. No build step and no dependencies.

## Structure

- `index.html`, `about.html`, `work.html`, `contact.html`: pages
- `style.css`: shared design system and home page styles
- `about.css`, `work.css`, `contact.css`: page-specific styles
- `script.js`: navigation, scroll animations, page transitions and contact form handling
- `google533dfacb851c6bc1.html`: Google Search Console verification file, do not edit or rename

## Run locally

Open `index.html` in a browser, or serve the folder with any static server.

## Deploy

Works on any static host (GitHub Pages, Netlify, Vercel, Cloudflare Pages). Upload the whole folder as is.
